Highly Available Webpage on AWS

This webpage is delivered through a scalable AWS architecture designed for availability, global access and automatic scaling.

View architecture

Project objective

The objective is to deploy a simple webpage using AWS services that support high availability, low-latency global delivery and automatic backend scaling.

AWS architecture

CloudFront

Provides global content delivery through AWS edge locations.

Application Load Balancer

Distributes HTTP requests across healthy web servers.

EC2 Auto Scaling

Maintains capacity across multiple Availability Zones and can scale with demand.

Request flow

User → CloudFront → Application Load Balancer → EC2 Auto Scaling Group

Infrastructure as Code

The infrastructure is defined with Terraform so the environment can be reproduced from code instead of being configured manually.
